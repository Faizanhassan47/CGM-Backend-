# CGM Backend API

Production-ready ASP.NET Core Web API service for the Continuous Glucose Monitoring (CGM) Platform.

## Quick Start
1. Configure .env with database connection string.
2. Run API:
   `dotnet run --project CGM.Api/CGM.Api.csproj --urls "http://0.0.0.0:5232"`
3. Swagger UI: http://localhost:5232
